# IBM Plex Sans

Source: https://github.com/IBM/plex/tree/1da12f02587b630c07e92692d21492d722f53614/packages/plex-sans/fonts/complete/ttf

Eight unmodified static TrueType faces (Regular, Medium, SemiBold, Bold and their true italics). Licensed under SIL OFL 1.1; see IBMPlexSans-LICENSE.txt.

PostScript names: Regular `IBMPlexSans`, Medium `IBMPlexSans-Medm`, SemiBold `IBMPlexSans-SmBld`, Bold `IBMPlexSans-Bold`; Expo aliases are separately registered. Default 0–9 advance widths are all 600 units in these faces, so stable numeric alignment does not require a separate mono font.
